# Demo Script

## Story

Cloud Migration Cockpit helps a migration consultant assess a messy on-prem commerce system, decide if and how it should move to the cloud, explain the reasoning to executives, and prepare planning artifacts without jumping straight into risky execution.

## Flow

1. Open the marketing homepage and position the product as an AI-native migration assessment cockpit.
2. Enter the app shell and open the seeded `LegacyCart` migration project.
3. Show the readiness score, top blockers, and recommendation summary.
4. Open the dependency graph and explain the system's database, jobs, NFS storage, Jenkins deploy pipeline, SOAP gateway, and SFTP dependencies.
5. Open findings to show evidence-backed blockers such as hardcoded secrets, leaked PII in logs, and unsupported runtimes.
6. Compare AWS, GCP, and Azure recommendations and explain the recommended landing pattern.
7. Show cost/ROI and risk/compliance summaries for technical and business stakeholders.
8. Run a what-if scenario such as “database first” vs “lift-and-shift with guardrails.”
9. Open generated artifacts: architecture diagram, migration roadmap, Terraform starter, security checklist, and monitoring checklist.
10. Show approval center and audit log to reinforce safe, governed execution.
11. End in stakeholder chat and report export to show the product works for both technical and non-technical audiences.

## Key Messages

- Every recommendation is backed by evidence.
- The product does not hide uncertainty; it exposes confidence and assumptions.
- Planning is approval-gated and execution-safe by design.
- The architecture is ready for live connectors and AWS-first execution later.
