# Presentation Outline

## Slide 1: Title

Cloud Migration Cockpit  
AI-Native Migration Assessment and Planning for MSPs

## Slide 2: The Problem

- Cloud migrations are slow, risky, and hard to explain.
- Existing tools are either infra generators or cost calculators.
- Consultants still stitch together evidence, spreadsheets, and slide decks by hand.

## Slide 3: The Product

- Hosted control plane + local worker
- Evidence-backed migration recommendation engine
- Executive and technical outputs in one workflow
- Approval-gated planning and future execution

## Slide 4: Why It Wins

- Parallel specialist agents with critics and evals
- Strong citation model
- Scenario analysis and governance, not generic LLM summaries
- Built-in factory for new tools and connectors

## Slide 5: Live Demo

- Marketing site
- Seeded legacy app assessment
- Provider comparison and readiness score
- Scenario analysis
- Reports and artifacts
- Approval trail

## Slide 6: Architecture

- Next.js cockpit
- FastAPI orchestration API
- Local worker
- PostgreSQL, Redis, MinIO
- Deterministic assessment swarm with future LangGraph/queue path

## Slide 7: Expansion Path

- GitHub and Azure Repos ingestion
- Real LLM-backed specialist agents
- AWS dry-run execution adapter
- Multi-cloud inventory and action workflows

## Slide 8: Ask

- Pilot with MSPs and cloud consultancies
- Validate real migration dossiers
- Expand from assessment to governed execution
